# IQ Floating Signal

Android floating-signal app source package.

## Project files
The original source archive is preserved at `IQ_Floating_Signal_Source_Ready-1.zip`. It contains an Android Studio project under `iqoption_floating_signal_app/`, including Java source, Android manifest, Gradle build files, a Bengali README, and a GitHub Actions workflow.

## Build
1. Download and extract `IQ_Floating_Signal_Source_Ready-1.zip`.
2. Open the `iqoption_floating_signal_app` folder in Android Studio.
3. Let Gradle sync, then run **Build > Make Project**.
4. Install and test the generated APK on an Android device.

**Important:** A successful GitHub upload is not proof that the app builds or that a submission is complete. Floating-window permission may need to be enabled in Android settings before the overlay works.
